# OrganicChemHub v2.3 开发文档

版本：v2.4
日期：2026-08-03
基准：v2.2

---

## 1. 产品定位

OrganicChemHub 是面向本科有机化学学习和考研复习的内容管理型网站。核心价值不是自动生成结构式，而是把反应知识、图片、考点、路线和学习记录整理成可检索、可维护、可持续扩充的资料库。

当前产品主线：

- 人名反应库。
- 常见有机反应库。
- 合成路线库。
- 学习资料。
- 公告、反馈、站内消息。
- 用户收藏、笔记和学习进度。
- 后台内容质量运营。
- 前台访问统计。
- 内容质量增强与图片审核。

---

## 2. 架构原则

1. Django Admin 是标准内容管理层。
2. 复杂运营工具使用专用后台页面。
3. 前台只展示已发布内容。
4. 结构式通过后台上传图片维护。
5. 机理图可选，方程式图和缩略图是发布质量检查项。
6. 人名反应和常见有机反应分库管理、分入口展示。
7. 后续版本优先提升内容质量和学习体验。

---

## 3. 核心模型

### 3.1 人名反应 `NamedReaction`

用于管理具有明确命名来源的人名反应。

主要字段：

- 中文名。
- 英文名。
- URL 标识。
- 分类。
- 标签。
- 官能团。
- 摘要。
- 反应条件。
- 机理描述。
- 考研考点。
- 适用范围。
- 使用限制。
- 参考来源。
- 方程式图。
- 机理图。
- 缩略图。
- 多张反应附图。
- 状态。

### 3.2 常见有机反应 `GeneralReaction`

用于管理不一定以人名命名、但考研和教材中常见的有机反应。

字段结构与人名反应基本一致，但分类体系独立，前台入口和页面标题独立。

### 3.3 合成路线 `SyntheticRoute`

用于管理目标产物及其合成步骤。

主要字段：

- 目标产物名称。
- 目标产物图片。
- 路线摘要。
- 难度。
- 优点。
- 缺点。
- 来源。
- 状态。
- 关联反应。

### 3.4 路线步骤 `RouteStep`

用于描述合成路线中的单步反应。

主要字段：

- 步骤序号。
- 标题。
- 反应物图片。
- 产物图片。
- 试剂。
- 反应条件。
- 产率。
- 关联反应。

### 3.5 访问统计 `VisitCounter`

用于记录网站和内容详情页访问量。

主要字段：

- 统计键。
- 统计名称。
- 总访问量。
- 今日访问量。
- 今日日期。
- 更新时间。

## 4. 发布规则

反应发布前必须具备：

- 摘要。
- 反应条件。
- 考研考点。
- 参考来源。
- 方程式图。
- 缩略图。

机理图不强制，因为有些反应不要求掌握机理。

v2.2 起，方程式图可以通过多张反应附图满足发布检查；缩略图仍建议单独上传，保证列表页展示稳定。

v2.1 新增 `publish_ready_content` 命令，用于自动发布完整草稿：

```bash
python manage.py publish_ready_content --dry-run
python manage.py publish_ready_content
```

不完整内容会保持草稿状态。

## 6. 前台结构

### 6.1 首页

- 搜索入口。
- 人名反应、常见有机反应和合成路线快速入口。
- 前台内容状态。
- 网站总访问量和今日访问量。
- 最近更新的人名反应。
- 最近更新的常见有机反应。
- 合成路线入口。
- 分类和标签。
- 意见反馈表单。

首页“进入后台维护”按钮仅管理员可见。

### 6.2 反应库

人名反应和常见有机反应使用不同标题、入口和视觉主题，避免用户混淆。

### 6.3 详情页

详情页优先展示图片、摘要、条件、机理、考点、适用范围、限制和参考来源，同时支持收藏、笔记和学习进度。

反应详情页和合成路线详情页展示本页总访问量和今日访问量。

---

## 7. 权限设计

- 超级管理员：拥有全部权限。
- 内容编辑员：维护反应、路线、资料和分类。
- 运营员：处理公告、反馈和站内消息。

初始化角色：

```bash
python manage.py setup_admin_roles
```

## 8. v2.3 变更范围

### 已实现

- 新增 `VisitCounter` 访问统计模型。
- 新增前台访问统计中间件，自动统计前台 GET 访问。
- 首页展示网站总访问量和今日访问量。
- 人名反应、常见有机反应和合成路线详情页展示本页总访问量和今日访问量。
- 后台新增访问统计只读列表。

### 验证重点

- 首页访问会增加网站访问量。
- 反应详情页访问会增加该反应访问量。
- 合成路线详情页访问会增加该路线访问量。
- 后台、静态文件和媒体文件访问不计入网站访问量。
- 访问统计后台不可手动新增或修改。

## 9. 后续开发方向

后续版本优先做：

1. 内容质量补全看板。
2. 图片审核状态。
3. 考研专题学习页。
4. 合成路线扩充。
5. 导入错误报告。
6. 操作审计和备份恢复。

不再把复杂结构解析能力作为产品主线。

本地素材目录：`data/reaction_image_library/` 为人工整理的反应图片素材库，`data/source/` 保存数据库建设指引和考研反应整理资料；两者均不进入 Git 和生产服务器。
