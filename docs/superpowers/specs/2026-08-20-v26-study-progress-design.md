# v2.6 学习进度与复习系统设计规格

## 1. 版本信息

- 版本：v2.6
- 标题：学习进度与复习系统 - 专题进度、复习清单与最近学习
- 日期：2026-08-20
- 基准版本：v2.5（已完成，2026-08-20）

## 2. 产品目标

在 v2.5 专题学习的基础上补齐个人学习闭环：用户从专题进入内容 → 在详情页或专题页标记学习状态 → 个人中心聚合展示专题进度与复习清单 → 按最近学习记录回顾。

本版本坚持轻量迭代：**不新增任何数据模型**，全部复用现有 `StudyProgress`（通用内容关联 + 路线关联）、`Favorite`、`StudyNote` 和 v2.5 的 `StudyTopic`；不引入间隔重复算法、提醒推送或邮件通知。

## 3. 功能范围

### 3.1 专题进度

专题详情页新增"我的专题进度"区块（仅登录用户可见）：

- 已学 X / 总数 Y：总数 = 专题关联的**已发布**人名反应 + 常见有机反应 + 合成路线数量；已学 = 其中用户标记为"已学"的数量。
- 完成度进度条：`percent = round(learned / total * 100)`，total 为 0 时显示"暂无内容"。
- 关联反应卡片和路线条目显示用户当前状态徽标（待学习 / 已学 / 待复习），无记录时不显示徽标。
- 支持在专题详情页**内联切换**学习状态：每个反应/路线卡片提供与详情页一致的三个状态选项（待学习 / 已学 / 待复习），提交到现有 `update_progress` 端点，不新增 URL。

### 3.2 复习清单

个人中心"复习清单"区块：

- 展示用户全部"待复习"记录（人名反应、常见有机反应、合成路线）。
- 排序依据：最近标记为"待复习"的时间（`updated_at` 倒序）。本版本不引入"到期时间"字段，如需真正到期提醒，留待后续版本扩展 `review_at` 字段。
- 每条显示：内容名称、标记时间、所属专题（如该内容被某个已发布专题关联，显示第一个专题名称，可点击直达专题详情）。
- 全量展示（不分页，条目少时直接列出；超过 20 条时截断并提示）。

### 3.3 最近学习记录

个人中心"最近学习"区块：

- 展示最近发生学习状态变更的记录（`StudyProgress` 按 `updated_at` 倒序，取最近 10 条）。
- 每条显示：内容名称、状态（待学习 / 已学 / 待复习）、最近更新时间。
- 点击进入内容详情页。

### 3.4 个人中心复习区块增强

- 新增"专题进度"卡片列表：每个已发布专题一行，显示专题名称、进度条、完成度（如 `3/12`），点击直达专题详情。
- 现有"复习入口"三栏（待学习 / 待复习 / 已学）保留，条目上限从 8 条调整到 6 条，为新增区块留出空间；复习清单全量入口独立成区块。

### 3.5 服务层

新增 `reactions/services/progress.py`，集中提供：

- `topic_progress(user, topic)`：返回 `{total, learned, review, pending, percent}` 或 `None`（匿名用户）。
- `topic_status_map(user, topic)`：返回内容 → 状态映射，供模板渲染状态徽标。
- `user_topic_summary(user)`：返回所有已发布专题的进度摘要列表 `[{topic, total, learned, percent}]`，按 `sort_order` 排序。
- `review_queue(user)`：待复习记录查询集，`-updated_at` 排序，`select_related("route")`。
- `recent_activity(user, limit=10)`：最近学习记录查询集，`-updated_at` 排序。

视图层只调用服务层，不重复写统计逻辑。

## 4. 数据和权限规则

- 进度、复习清单、最近学习仅展示**本人**数据；匿名用户不显示任何进度区块和控件。
- 专题进度只统计专题关联的**已发布**内容，与前台展示规则一致；草稿/归档内容不计入总数。
- 草稿/归档专题不在个人中心专题进度列表中出现。
- 内联切换沿用现有 `UpdateProgressView` 的权限（`LoginRequiredMixin`）与 CSRF 保护。
- 不删除、不迁移、不新增用户数据；现有 `StudyProgress` 记录保持兼容。

## 5. 实现边界

- 不新增模型、不修改 `StudyProgress` / `StudyTopic` / `ReactionComparison` 表结构。
- 不引入间隔重复算法、到期提醒、站内信推送或邮件通知。
- 不修改反应/路线详情页现有收藏、进度、笔记控件。
- 不移动 `organic_chem_hub/`、`reactions/`、`templates/`、`static/` 目录。
- 不引入新的前端框架；复用 `quick-panel`、`list-group`、`badge`、Bootstrap progress 组件和现有 `site.css` 变量。
- 专题详情内联切换复用现有 `update_progress` URL，不新增路由。

## 6. 测试验收标准

### 服务层

- 专题进度计算正确：空专题返回 total=0 不报错；含人名反应、常见反应和路线时总数正确；只统计已发布内容。
- `topic_progress` 对匿名用户返回 `None`。
- `user_topic_summary` 只包含已发布专题，按 `sort_order` 排序。
- `review_queue` / `recent_activity` 按时间倒序、数据正确。

### 个人中心

- 登录用户个人中心展示：专题进度列表、复习清单、最近学习记录。
- 匿名访问个人中心被重定向到登录页（现有保护不回退）。
- 标记"已学"后，专题进度、已学统计同步变化。

### 专题详情

- 登录用户看到"我的专题进度"区块、进度条、状态徽标和内联切换控件。
- 匿名用户看不到进度区块与内联控件。
- 内联切换后刷新页面，徽标和进度条正确更新。
- 草稿专题详情页 404（现有规则不回退）。

### 回归

- 现有 `reactions.tests` 全部通过。
- `manage.py check` 通过。
- `makemigrations --check --dry-run` 无未生成迁移（本版本无迁移）。
- `git diff --check` 通过。

4. 文档同步：README、CHANGELOG、规划文档、部署说明。
5. 最终验收（全量测试、check、collectstatic、git 检查）与发布。
