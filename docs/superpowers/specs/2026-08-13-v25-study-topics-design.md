# v2.5 考研专题学习设计规格

## 1. 版本信息

- 版本：v2.5
- 标题：考研专题学习 - 专题分类、易混反应对比与复习入口
- 日期：2026-08-13
- 基准版本：v2.4.1

## 2. 产品目标

将 OrganicChemHub 从反应查询工具扩展为考研复习入口。管理员可以把已经维护好的人名反应、常见有机反应和合成路线组织为专题，并维护易混反应对比；用户可以从专题进入具体内容，并在个人中心集中查看待学习、已学和待复习内容。

本版本坚持人工维护内容，不引入 SMILES、RDKit、结构式编辑器、子结构检索或 AI 自动生成内容。

## 3. 功能范围

### 3.1 考研专题

新增 `StudyTopic` 模型，字段包括：

- 专题名称。
- URL 标识。
- 专题简介。
- 学习目标。
- 考试重点。
- 排序值。
- 发布状态。
- 创建时间和更新时间。
- 关联人名反应。
- 关联常见有机反应。
- 关联合成路线。

专题通过 Django Admin 维护。只有已发布专题在前台显示；专题关联内容只使用前台当前已发布的反应和路线。

首批专题建议：

- 羰基化学。
- 芳香取代。
- 氧化还原。
- 重排反应。
- 碳链增长。
- 鉴别反应。

### 3.2 易混反应对比

新增 `ReactionComparison` 模型，字段包括：

- 对比标题。
- URL 标识。
- 对比说明。
- 反应 A 和反应 B。
- 适用底物差异。
- 反应条件差异。
- 主要产物差异。
- 常见考法。
- 易错点。
- 发布状态。
- 排序值。
- 创建时间和更新时间。

反应 A、反应 B 使用通用内容关联，支持人名反应或常见有机反应，但同一条对比必须选择两个不同的反应。前台只展示已发布的对比和已发布的关联反应。

### 3.3 前台页面

新增 URL：

- `/study-topics/`：专题列表。
- `/study-topics/<slug>/`：专题详情。
- `/reaction-comparisons/`：易混反应对比列表。
- `/reaction-comparisons/<slug>/`：易混反应对比详情。

专题列表支持按标题和简介搜索，按排序值或更新时间排序。专题详情展示简介、学习目标、考试重点、关联人名反应、关联常见反应、关联合成路线和易混对比入口。

易混反应对比列表支持标题搜索和分页。详情页使用并列结构展示反应 A、反应 B、适用底物、条件、产物、常见考法和易错点，并提供两个反应详情入口。

首页新增“考研专题学习”和“易混反应对比”快速入口。页面复用现有前台 UI、颜色变量、卡片、分页和导航组件，不另起视觉体系。

### 3.4 复习入口

复用现有 `StudyProgress`、`Favorite` 和个人中心，不新增重复的进度模型。

个人中心新增复习区块，展示：

- 待学习反应。
- 待复习反应。
- 已学内容数量。
- 收藏内容。
- 最近学习内容。

用户仍通过反应和路线详情页现有控件更新学习状态。专题详情页中的反应可以直接进入详情页完成学习标记。

### 3.5 专题访问统计

复用 v2.3 的 `VisitCounter` 和访问统计服务。专题详情页和易混反应对比详情页各自记录总访问量和今日访问量，并使用现有前台访问统计卡片样式。

## 4. 数据和权限规则

- 专题和对比内容由 Django Admin 管理。
- 内容编辑员可以维护专题、对比内容及关联关系。
- 运营员可以查看内容，但不能修改核心反应关联或发布状态，遵循现有角色权限配置。
- 草稿和归档专题、对比内容不能通过前台 URL 访问。
- 已发布专题中的草稿反应不在关联内容区块展示。
- 删除专题或对比内容不删除反应、路线和用户学习记录。
- 反应 A 和反应 B 必须不同。

## 5. 实现边界

- 不移动现有 `organic_chem_hub/`、`reactions/`、`templates/`、`static/` 目录。
- 不修改现有反应图片上传和审核逻辑。
- 不引入新的前端框架。
- 不引入 SMILES、RDKit、Ketcher 或子结构检索。
- 关联反应使用显式 ManyToMany/通用外键设计，避免依赖旧版 `Reaction` 遗留模型。

## 6. 测试验收标准

### 模型和后台

- 专题可以创建、编辑、发布和归档。
- 对比可以创建、编辑、发布和归档。
- 对比不能关联同一个反应两次。
- Admin 列表能显示状态、排序和关联内容。

### 前台

- 未发布专题和对比页面返回 404 或不可见。
- 已发布专题列表、详情页正常展示。
- 已发布对比列表、详情页正常展示。
- 搜索、分页和首页入口正常。
- 关联草稿内容不会在前台展示。
- 专题和对比详情页显示访问统计。

### 用户学习

- 个人中心显示待学习、已学和待复习内容。
- 详情页更新学习状态后，个人中心统计同步变化。
- 未登录用户不能修改学习状态。

### 回归

- 现有 `reactions.tests` 全部通过。
- `manage.py check` 通过。
- `makemigrations --check --dry-run` 无未生成迁移。
- `git diff --check` 通过。
