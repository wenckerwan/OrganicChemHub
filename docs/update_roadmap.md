## 2. 更新原则

1. **内容优先**：先把资料库做到考研可用（80+ 反应、20+ 路线），再做花哨功能。
2. **图片补全优先**：修复 18 条无图反应的缺口是第一优先级。
3. **实用功能优先于智能功能**：收藏、笔记、数据导入导出比 AI 路线设计更有用。
4. **小版本快速迭代**：每次聚焦一个小目标。

### 3.2 v1.0 — 内容补全（当前最紧急）

**目标**：所有 46 条反应都有结构式图片，总反应量扩到 80+。

#### 任务清单

**A. 补全 18 条无 SMILES 反应的图片**

以下反应需要管理员**先查找 SMILES 或手工绘制结构式**：

| 反应 | 建议方式 |
|------|---------|
| Gabriel 合成、Sandmeyer 反应 | 查找标准 SMILES → RDKit 生成 |
| Mannich 反应、Robinson 环化 | 查找标准 SMILES → RDKit 生成 |
| Knoevenagel、Perkin、Reformatsky | 这些含经典缩合 SMILES，较易查到 |
| Claisen 重排、Cope 重排、Fries 重排 | 可自行绘制 |
| Dieckmann、Darzens、Hantzsch | 可自行绘制 |
| Schmidt、Wolff、Stork、Reimer-Tiemann、Kolbe-Schmitt | 可以逐个查找补全 |

**操作流程：**

```
查找 SMILES → 在 Admin 中写入对应反应 → 服务器运行
python scripts/generate_reaction_images.py
python manage.py import_reaction_images
python manage.py collectstatic --noinput
```

**B. 扩充反应库到 80+ 条**

新增约 40 条考研常见反应（如：Mukaiyama  aldol、Bamford-Stevens、Shapiro、McMurry、Wacker 氧化、Sharpless 环氧化、Sonogashira、Suzuki、Heck 等）。

**C. 新建 `scripts/supplement_reactions.py`**

批量从 CSV/Excel 导入新反应的自动化脚本。

### 3.3 v1.1 — 合成路线增强

**目标**：路线库从 1 条扩到 20+ 条，完善路线详情页展示。

#### 功能范围

- 新增目标产物结构式图片上传指引
- 路线步骤增加反应物/产物图片字段
- 扩充考试常考合成路线（如：苯酚→水杨酸、甲苯→苯甲酸、多步天然产物合成等）
- 路线详情页 UI 优化：步骤间箭头连接、试剂条件可视化

---

### 3.4 v1.2 — 后台工具增强

**目标**：提高管理员录入效率。

#### 功能范围

- **CSV/Excel 导入**：用 `django-import-export` 或自建脚本，支持批量导入反应名称、SMILES、条件等
- **导出功能**：反应列表导出为 CSV
- **批量图片上传**：在后台上传 zip 批量解压
- **内容质量仪表盘**：列出缺少图片、缺少摘要、缺少参考来源的反应

---

### 3.5 v1.3 — 用户系统

**目标**：支持个人学习管理。

#### 功能范围

- 注册/登录（Django 内置用户系统）
- 收藏反应和路线（`ManyToManyField` 或独立 `Favorite` 模型）
- 个人笔记（每个反应下写笔记，仅自己可见）
- 最近浏览记录

---

### 3.6 v1.4 — 结构式检索

**目标**：基于 RDKit 做子结构搜索。

#### 功能范围

- 用户输入分子 SMILES 搜索包含该子结构的反应
- 官能团搜索（利用已有 `FunctionalGroup.smarts`）
- 搜索结果展示匹配的结构式高亮
- 对 300-500 条规模下性能可接受（应用层扫描）

---

### 3.7 v1.5 — 学习专题

**目标**：从查询工具升级为复习工具。

#### 功能范围

- 按主题归类（碳链增长、官能团转化、氧化还原、重排）
- 易混反应对比页（Wittig vs Peterson、Aldol vs Claisen）
- "考研高频"专题入口
- 学习路径建议

## 5. 技术债务与优化

### 近期可做的零碎改进

| 项目 | 优先级 | 说明 |
|------|--------|------|
| Wittig 反应 SVG 生成 | 高 | CPPh3 非标准 SMILES，手工绘制或改用正确 SMILES |
| 旧 lecture_* PNG 清理 | 中 | 替换完成后可删除 `static/img/reactions/` 目录 |
| 测试覆盖率提升 | 中 | 补充图片上传、fallback、移动端相关测试 |
| PostgreSQL 迁移 | 低 | 数据量增大后可考虑从 SQLite 迁移 |

### 不建议立即开发的功能

- AI 自动合成路线设计（需要大量训练数据）
- 移动端 App（Web 端完善后再考虑）
- 用户社区和讨论区
- 完整前后端分离（SPA 重构）
- 在线结构编辑器（Ketcher 集成）
