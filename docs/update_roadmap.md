# OrganicChemHub 未来更新简表

当前版本：**v3.0 公开稳定版（开发中）**
下一版本：**待定**

后续开发不再围绕文本结构式生成、结构编辑器或子结构检索展开。项目主线是：图片结构式上传与审核、内容质量、后台运营、考研专题和合成路线扩充。

## v4.0 开发中（2026-08-21）

- 评论/社区：`Comment` 模型（GFK 复用互动模式）、详情页评论区（登录评论/回复、匿名登录引导）、后台审核隐藏（写 OpLog）、个人中心"我的评论"。
- SEO 公开化：sitemap.xml + robots.txt、详情页独立 description/canonical/OG、404/500 友好错误页。
- 零新依赖（sitemaps 为 Django 内置）。

## v3.0 已交付（2026-08-20）

- 占位图服务 `placeholder.py`：缺图反应一键生成中性占位图，绑定字段后内容可发布、待替换真图。

- 内容就绪报告 `content_readiness_report`：统计 + `--export` 逐条 CSV。
- 发布流程闭环：`publish_ready_content` 写审计与批次；仪表盘占位图待替换计数。
- 零模型变更、零迁移。

## 近期优先级

1. 先补内容质量：缺图、缺条件、缺考点、缺参考来源（当前 82 条反应均为草稿，缺方程式图和缩略图）。
2. 再补路线规模：从少量示例扩展到可训练的路线库。
3. 再做专题学习：按考研常见模块组织内容（v2.5 已提供专题框架，待内容发布后填充）。
4. 最后强化运营审计：让导入、发布、回滚都有记录可查。
