# OrganicChemHub 未来更新简表

当前版本：**v2.0 正式版**
下一版本：**v2.1 内容发布完善**

后续开发不再围绕文本结构式生成、结构编辑器或子结构检索展开。项目主线是：图片结构式上传与审核、内容质量、后台运营、考研专题和合成路线扩充。

---

## 版本计划

| 版本 | 主题 | 最值得做的功能 |
|------|------|---------------|
| v2.1 | 内容发布完善 | 首页前台内容状态、后台可发布草稿统计、完整草稿自动发布命令 |
| v2.2 | 内容质量补全 | 缺图/缺字段优先级看板、图片审核状态、补全建议 |
| v2.3 | 考研专题学习 | 专题页、易混反应对比、高频考点集合、个人复习路径 |
| v2.4 | 合成路线扩充 | 路线步骤编辑增强、路线筛选、关键步骤和优缺点展示 |
| v2.5 | 运营与审计 | 内容批次、操作日志、导入错误报告、备份恢复流程 |
| v3.0 | 公开稳定版 | 内容规模、学习路径、后台质量运营和部署流程全部稳定 |

---

## v2.1 验收清单

- 首页显示“前台内容状态”。
- 后台仪表盘显示“可发布草稿”。
- `publish_ready_content` 只发布完整草稿。
- 缺方程式图、缺缩略图、缺条件、缺考点、缺参考来源的内容不会被自动发布。
- README 和更新日志同步到 v2.1。

---

## 近期优先级

1. 先补内容质量：缺图、缺条件、缺考点、缺参考来源。
2. 再补路线规模：从少量示例扩展到可训练的路线库。
3. 再做专题学习：按考研常见模块组织内容。
4. 最后强化运营审计：让导入、发布、回滚都有记录可查。
