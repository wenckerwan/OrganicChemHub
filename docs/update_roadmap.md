# OrganicChemHub 未来更新简表

当前版本：**v2.7 合成路线扩充（开发中）**
下一版本：**v2.8 运营与审计**

后续开发不再围绕文本结构式生成、结构编辑器或子结构检索展开。项目主线是：图片结构式上传与审核、内容质量、后台运营、考研专题和合成路线扩充。

## v2.7 实现范围（2026-08-20）

- 目标官能团筛选：路线列表按官能团筛选（与难度/搜索/排序叠加），详情页官能团徽标可回跳列表。
- 关键步骤标记：`RouteStep.is_key_step`，详情页时间线高亮"关键步骤"。
- 后台增强：内联步骤图片缩略图预览、关键步骤编辑、步骤序号连续性校验、缺图提醒。
- 模型变更：`SyntheticRoute.related_functional_groups` 复用现有官能团模型。
- 不实现步骤拖拽排序与 SMARTS 检索；路线库 20+ 条由内容运营达成。

## 近期优先级

1. 先补内容质量：缺图、缺条件、缺考点、缺参考来源（当前 82 条反应均为草稿，缺方程式图和缩略图）。
2. 再补路线规模：从少量示例扩展到可训练的路线库。
3. 再做专题学习：按考研常见模块组织内容（v2.5 已提供专题框架，待内容发布后填充）。
4. 最后强化运营审计：让导入、发布、回滚都有记录可查。
