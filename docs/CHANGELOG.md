## 版本历史

### v2.5 考研专题学习（2026-08-20，已完成）

- 新增 `StudyTopic` 考研专题模型，支持关联人名反应、常见有机反应和合成路线。
- 新增 `ReactionComparison` 易混反应对比模型，反应 A/B 使用通用内容关联，强制两个反应不同。
- 新增专题和对比前台列表/详情页，支持搜索、分页、访问统计和只展示已发布内容。
- 首页新增考研专题和易混反应对比入口。
- 个人中心新增待学习、待复习和已学内容复习区块。
- 用户互动模型（`Favorite`/`StudyNote`/`StudyProgress`）改用通用内容关联，同时支持新老反应库；详情页收藏、笔记和学习进度控件正式启用。
- 专题详情页补充易混反应对比入口。

### v2.4 内容质量增强（2026-08-03）

- `ReactionImage` 新增图片审核状态：待审核、已通过、需重画。
- 后台支持按审核状态筛选图片，并批量标记已通过或需重画。
- 内容质量仪表盘增加图片审核数量和高访问但未完整内容列表。
- 人名反应和常见反应管理列表增加总访问量、今日访问量。

### v2.3 访问统计（2026-08-03）

- 新增 `VisitCounter` 访问统计模型，支持网站、反应详情页和合成路线详情页计数。
- 新增前台访问统计卡片：首页显示网站总访问量/今日访问量，详情页显示本页总访问量/今日访问量。
- 新增 `SiteVisitCounterMiddleware`，自动统计前台 GET 访问，排除后台、静态文件和媒体文件。
- 后台新增“访问统计”只读列表，防止人工误改统计值。

### v2.2 反应多图上传（2026-08-03）

- 新增 `ReactionImage` 反应附图模型，支持人名反应和常见有机反应共用。
- 方程式图、机理图、反应条件附图、机理文字附图、考点附图均支持多张上传，每个区域上限 10 张。
- 条件、机理文字和考点附图为可选项，不影响发布。
- 多张方程式图可满足发布完整度检查，仪表盘不再误判为缺方程式图。
- 详情页新增按区域展示的附图画廊。

### v2.1 内容发布完善（2026-08-03）

- 首页增加“前台内容状态”，展示已发布人名反应、常见有机反应、合成路线和待发布完整内容数量。
- 后台内容质量仪表盘增加“可发布草稿”统计。
- 新增 `publish_ready_content` 管理命令，完整草稿可批量发布，缺图或缺关键字段内容自动跳过。
- 清理旧结构式生成运行依赖，前台结构式展示继续以后台上传图片为准。

### v2.0 后台内容管理正式版（2026-08-03）

- 人名反应和常见有机反应拆成两套内容库。
- Django Admin 作为标准内容管理层，专用页面负责仪表盘、CSV 导入、图片维护、消息群发和资料上传登记。
- 前台保留现有 UI 风格，同时区分人名反应库和常见有机反应库。
- 反应方程式图和缩略图为发布质量检查项，机理图可选。
