# OrganicChemHub 更新日志

> 当前基准版本：v2.0 正式版
> 当前开发版本：v2.1
> 更新方向：图片结构式、内容质量、后台运营、学习体验。不再规划文本结构式生成、结构编辑器或子结构检索路线。

## 后续规划

- 缺图、缺考点、缺条件、缺参考来源的内容分组看板。
- 后台一键筛出“最值得优先补全”的反应。
- 反应图片审核状态：待上传、待审核、已通过、需重画。
- 发布前质量提示进一步细化到字段和图片类型。

### v2.3 — 考研专题学习

- 按“羰基反应”“芳香取代”“氧化还原”“重排反应”等主题组织内容。
- 易混反应对比页。
- 高频考点集合页。
- 个人学习路径和复习进度聚合。

### v2.4 — 合成路线扩充

- 路线步骤编辑体验增强。
- 按目标官能团、难度、路线长度筛选路线。
- 路线优缺点对比和关键反应提示。
- 路线库从少量示例扩展到可用于复习训练的规模。

### v2.5 — 运营与数据维护

- 管理员操作审计增强。
- 内容更新批次记录。
- CSV 导入错误报告下载。
- 数据备份和恢复说明完善。

## 版本历史

### v2.1 内容发布完善（2026-08-03）

- 首页增加“前台内容状态”，展示已发布人名反应、常见有机反应、合成路线和待发布完整内容数量。
- 后台内容质量仪表盘增加“可发布草稿”统计。
- 新增 `publish_ready_content` 管理命令，完整草稿可批量发布，缺图或缺关键字段内容自动跳过。
- 清理旧结构式生成运行依赖，前台结构式展示继续以后台上传图片为准。

### v2.0 后台内容管理正式版（2026-08-03）

- 人名反应和常见有机反应拆成两套内容库。
- Django Admin 作为标准内容管理层，专用页面负责仪表盘、CSV 导入、图片维护、消息群发和资料上传登记。
- 前台保留现有 UI 风格，同时区分人名反应库和常见有机反应库。
- 反应方程式图和缩略图为发布质量检查项，机理图可选。

### v1.6 前台反应库 UI 与导航分流（2026-08-03）

- 人名反应库使用蓝色主题。
- 常见有机反应库使用青绿色主题。
- 修复旧导航项导致常见反应进入人名反应库的问题。
- 首页“进入后台维护”按钮仅管理员可见。

### v1.5 反馈升级与站内消息（2026-07-29）

- 反馈系统支持类型分类、状态流转、管理员公开回复和内部备注。
- 新增站内消息中心、未读红点、全部已读。
- 公告发布、反馈回复和状态变更可触发站内消息。

### v1.4 用户体系与个性化（2026-07-29）

- 用户注册、登录、退出。
- 收藏反应和路线。
- 私人笔记和学习进度。
- 个人中心展示收藏、笔记、反馈和进度统计。

### v1.3 公告弹窗与意见反馈（2026-07-29）

- 公告栏、重要公告弹窗、置顶和显示时间段。
- 前台意见反馈表单。
- 后台可查看和处理反馈。

### v1.2 后台工具增强（2026-07-29）

- CSV 导出。
- 内容质量仪表盘。
- 导入字段补充。
- Git 同步流程文档。
