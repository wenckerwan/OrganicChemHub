首次部署

面向宝塔面板托管的 OrganicChemHub 上线检查清单。

上线前检查

  • 安装 Python 项目运行环境。
  • 安装依赖并确认 Django 可运行。
  • 配置生产环境变量，包括 `SECRET_KEY`、`DEBUG`、`ALLOWED_HOSTS`。
  • 执行数据库迁移。
  • 创建管理员账号。
  • 收集静态文件。
  • 配置 Gunicorn 服务。
  • 在宝塔面板中配置 Nginx 反向代理。
  • 配置 HTTPS 和数据库备份。

常用命令

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py collectstatic --noinput
gunicorn organic_chem_hub.wsgi:application --bind 127.0.0.1:8000

宝塔面板要点

宝塔面板中建议使用 Python 项目管理器或 Supervisor 管理 Gunicorn，并用网站配置中的反向代理把域名转发到 `127.0.0.1:8000`。

静态文件目录应指向 `staticfiles`，数据库和媒体文件需要定期备份。
